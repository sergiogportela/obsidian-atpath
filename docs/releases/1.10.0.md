# AtPath 1.10.0

Copy or drag a file's GitHub link out of Obsidian.

## New

- **Copy path → as GitHub link** in the explorer and tab menus copies `[{repo}/{path}](https://github.com/{owner}/{repo}/blob/main/{path})` for a file or folder. Folders use `tree` and end in `/`.
- Select several items and choose **Copy GitHub links** to copy one link per line.
- **Copy GitHub link for current file** is available in the command palette and can take a hotkey.
- Dragging files or folders from the explorer into another app drops the same links as text. Drops inside Obsidian behave as before.

These appear only for items inside a checkout with a GitHub origin. Links always point at `main`. Turning off **Drag-and-drop repository links** restores Obsidian's own drag payload.

## Install

Requires **Obsidian 1.15 or newer**.

1. Download **atpath-1.10.0.zip** below and unzip it. The ZIP contains an `atpath` folder.
2. Move that folder into your vault's `.obsidian/plugins/` folder. Use your configured settings folder if it differs from `.obsidian`. On macOS, press **Cmd+Shift+.** in Finder to show hidden folders.
3. Restart Obsidian. Open **Settings → Community plugins**, turn on community plugins if prompted, and enable **AtPath**.

Already installed? Replace only `main.js`, `manifest.json` and `styles.css` in the existing `atpath` folder, then restart Obsidian. Keep your `data.json` settings file.

For updates through BRAT, add `sergiogportela/obsidian-atpath`.

See the [visual guide](https://github.com/sergiogportela/obsidian-atpath/blob/1.10.0/README.md) for usage and the [reference](https://github.com/sergiogportela/obsidian-atpath/blob/1.10.0/docs/reference.md) for details.

## Compatibility

Tested on macOS in Obsidian 1.15.1, including physical drags into TextEdit and into a note. Other operating systems, real-device mobile/Sync and live publication remain unverified. The submenu placement uses an internal Obsidian menu API with a top-level fallback.
