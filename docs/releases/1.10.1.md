# AtPath 1.10.1

A shorter **Copy path** menu.

## Changed

- **Copy path** now shows only **from vault folder** and **as GitHub link**. Obsidian's **as Obsidian URL** and **from system root** entries are hidden.
- Turn off **Compact copy path menu** in AtPath settings to show all formats again. Obsidian's **Copy Obsidian URL** command is unaffected.

## Install

Requires **Obsidian 1.15 or newer**.

1. Download **atpath-1.10.1.zip** below and unzip it. The ZIP contains an `atpath` folder.
2. Move that folder into your vault's `.obsidian/plugins/` folder. Use your configured settings folder if it differs from `.obsidian`. On macOS, press **Cmd+Shift+.** in Finder to show hidden folders.
3. Restart Obsidian. Open **Settings → Community plugins**, turn on community plugins if prompted, and enable **AtPath**.

Already installed? Replace only `main.js`, `manifest.json` and `styles.css` in the existing `atpath` folder, then restart Obsidian. Keep your `data.json` settings file.

For updates through BRAT, add `sergiogportela/obsidian-atpath`.

See [1.10.0](https://github.com/sergiogportela/obsidian-atpath/releases/tag/1.10.0) for GitHub link copying and drag-out, and the [reference](https://github.com/sergiogportela/obsidian-atpath/blob/1.10.1/docs/reference.md) for details.

## Compatibility

Tested on macOS in Obsidian 1.15.1. Hiding the native entries uses an internal Obsidian menu API; if it changes, the entries stay visible.
