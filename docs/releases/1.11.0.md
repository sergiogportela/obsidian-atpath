# AtPath 1.11.0

Tables keep the Markdown you wrote.

## New

- **Protect tables from reformatting**, on by default. In Live Preview, Obsidian rewrites a table's Markdown into padded, aligned columns as soon as you click a cell or move the cursor through it, even when you change nothing. With this setting on, tables in Live Preview are read-only: clicks and the cursor skip them, and links inside them still open.
- Tables also stay as written when a script or an agent rewrites a note you have open: if the reload leaves the cursor on a row of a table it changed, AtPath moves the cursor to the line above the table.
- Edit tables in Source mode or in a table plugin's own editor. To get Obsidian's table editor back, turn the setting off in AtPath settings; it applies at once.

**This changes how Obsidian behaves.** After updating, you cannot type into a table cell in Live Preview until you turn the setting off. The table editor's add-row, add-column and drag controls are hidden, text inside a table cannot be selected with the mouse, tables do not accept dragged text or files, and **Insert table** leaves the cursor below the new table instead of in its first cell. A note that begins with a table opens with the cursor below the table.

Not covered: typing a table in Live Preview behaves as before, so Obsidian's table editor can still take it over midway and pad it (type tables in Source mode), and undo or redo that returns the cursor into a table opens that editor.

## Fixed

- Clicking an AtPath link inside a table in Live Preview could make Obsidian write that table, reformatted, into the note the link opened. This fix does not depend on the new setting.

## Install

Requires **Obsidian 1.15 or newer**.

1. Download **atpath-1.11.0.zip** below and unzip it. The ZIP contains an `atpath` folder.
2. Move that folder into your vault's `.obsidian/plugins/` folder. Use your configured settings folder if it differs from `.obsidian`. On macOS, press **Cmd+Shift+.** in Finder to show hidden folders.
3. Restart Obsidian. Open **Settings → Community plugins**, turn on community plugins if prompted, and enable **AtPath**.

Already installed? Replace only `main.js`, `manifest.json` and `styles.css` in the existing `atpath` folder, then restart Obsidian. Keep your `data.json` settings file.

For updates through BRAT, add `sergiogportela/obsidian-atpath`.

See the [reference](https://github.com/sergiogportela/obsidian-atpath/blob/1.11.0/docs/reference.md#tables-in-live-preview) for what the setting covers and what it does not.

## Compatibility

Tested on macOS in Obsidian 1.15.1 with real mouse and keyboard input. Mobile and other operating systems were not tested. The setting recognizes tables and their controls by internal Obsidian names; if Obsidian changes them, the protection stops silently and its table editor returns.
