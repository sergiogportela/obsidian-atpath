# AtPath 1.9.0

Link notes to project files, count their text tokens locally, and collect context across repositories.

## Install

Requires **Obsidian 1.15 or newer**.

1. Download **atpath-1.9.0.zip** below and unzip it. The ZIP contains an `atpath` folder.
2. Move that folder into your vault's `.obsidian/plugins/` folder. Use your configured settings folder if it differs from `.obsidian`. On macOS, press **Cmd+Shift+.** in Finder to show hidden folders.
3. Restart Obsidian. Open **Settings → Community plugins**, turn on community plugins if prompted, and enable **AtPath**.
4. Turn **Use Wikilinks** off under **Settings → Files and links**. Open a note in a Git checkout in your vault and type `[[` to search for a file or folder.

Already installed? Replace only `main.js`, `manifest.json` and `styles.css` in the existing `atpath` folder, then restart Obsidian. Keep your `data.json` settings file.

For updates through BRAT, add `sergiogportela/obsidian-atpath`.

## Included

- Ordinary Markdown links across local Git repositories, with local navigation, backlinks, graph and rename support.
- Exact local o200k_base text counts, content-verified caching and faint explorer badges.
- `90_archive` and `00_llm` excluded from parent totals by default. A folder's `*` shows the omitted token counts. Existing customized exclusion lists are preserved; edit them in AtPath settings.
- Whole-link hover, new-tab/split/window menus and bullet-list drops on empty lines.
- Desktop file-symlink shortcuts, including `CLAUDE.md → AGENTS.md`, without duplicate folder counts.
- Recursive context copying and reviewed web-publishing previews.

See the [visual guide](https://github.com/sergiogportela/obsidian-atpath/blob/1.9.0/README.md) for usage and configuration.

## Compatibility

Desktop behavior was tested in Obsidian 1.15.0. Real-device mobile/Sync, physical OS drag/drop and live publication remain unverified. Token counts describe o200k_base text, not complete model requests. Native-link and explorer integration use internal Obsidian APIs; details are in the [reference](https://github.com/sergiogportela/obsidian-atpath/blob/1.9.0/docs/reference.md).
